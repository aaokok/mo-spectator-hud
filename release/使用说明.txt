 MO Spectator HUD（心灵终结 3.3.6 观战插件）使用说明
================================================================

【方案 A：桌面客户端一键启动（推荐）】
1. 打开游戏《心灵终结 3.3.6》，启动并进入对局或回放。
2. 双击运行当前目录下的 `mo_hud.exe`。
3. 程序会自动：
   - 启动本地后台服务（默认端口 127.0.0.1:8770）；
   - 自动托管并拉起数据桥 `hud_bridge.exe`；
   - 弹出 Web 管理控制台窗口（可调比分、比赛名、队列与单位开关）；
   - 在游戏上方生成透明置顶的 HUD 覆盖层，并自动跟随游戏窗口。
4. 全局快捷键：
   - Ctrl + Alt + H ：显隐 HUD 覆盖窗口
   - Ctrl + Alt + T ：置顶 / 取消置顶

【方案 B：OBS 导播推流配置】
若在 OBS 中叠加本插件：
1. 运行 `mo_hud.exe` 启动服务。
2. 在 OBS 来源中添加「浏览器」(Browser Source)。
3. URL 填入：http://127.0.0.1:8770/overlay
4. 宽度设为 1920，高度设为 1080（或与游戏分辨率相同），帧率建议 30 或 60。
5. 背景天然全透明，无需添加任何色键滤镜。

【方案 C：轻量 Python 独立服务（无客户端环境）】
若不需要桌面覆盖层窗口，仅需要 OBS 网页源：
1. 进入 `demo` 目录。
2. 双击 `启动覆盖层.bat`（或运行 `python serve.py`）。
3. 按照控制台提示将地址填入 OBS 浏览器源即可。

【常见排错】
- 杀毒软件误报：由于数据桥需要读取游戏内存，部分杀软可能会拦截，请添加白名单或点击允许。
- 数据未更新：请确保游戏版本为 MO 3.3.6，且进入了实际战斗画面。控制台页面内含有「环境自检」面板可快速定位故障。
