开对局前：游戏必须是窗口化

必读

只支持窗口化（Windowed Mode）或无边框窗口化（Borderless Windowed Mode）。 覆盖层是一层独立的置顶窗口，靠外部跟随游戏窗口来对齐；游戏处于独占全屏时它贴不上去， 直播画面里 HUD 会浮在桌面上或整段错位。

设置位置：游戏主菜单 →「选项 / Options」→「Display」页， 勾选 Windowed Mode；想保留全屏观感再勾 Borderless Windowed Mode。 游戏内分辨率建议与 OBS 画布一致，覆盖层对位最省事。

悬停看大图

参考图：红框里这两项就是要勾的。只勾 Windowed Mode 会有标题栏和边框； 同时勾 Borderless Windowed Mode 才是无边框的窗口化，覆盖层对位最省事。

鼠标停在上图会弹出原尺寸大图，移开即收起；点一下可以钉住，再点一次或按 Esc 关闭。

五分钟跑起来

从零到 OBS 出画面
1
确认游戏目录

打开「环境」页，看顶部那条汇总是不是绿色。若提示找不到游戏， 点「重新检测」；仍然失败就到「环境」里手动指定 gamemd.exe 所在目录。

2
进一局（先确认是窗口化）

游戏必须是窗口化或无边框窗口化，上一节有参考图。 然后正常启动 MO，用观战槽进对局。本程序不注入游戏、不改游戏文件， 只是只读地读内存和窗口状态，所以不需要额外装任何东西。

进对局后「总览」页的「对局」会变成绿色的「对局中」，说明数据通了。

3
让覆盖窗口贴住游戏

程序会自动找到游戏窗口并把覆盖层贴上去。切到别的软件时它会自动隐藏， 回游戏自动恢复（可在「画面」页关掉这个行为）。

如果 HUD 没出现，先看「画面」页右边的状态胶囊： 「未找到游戏」= 没识别到游戏窗口；「已隐藏」= 手动隐藏或失焦隐藏中。

4
接到 OBS

点右上角「复制 OBS 地址」，在 OBS 里添加「浏览器」源，把地址粘进去。 尺寸设成和游戏分辨率一致（如 1920×1080），勾选「关闭源时关闭页面」。

OBS 源和本地覆盖窗口加载的是同一份数据， 所以在「画面」页改的开关两端同时生效。

各页签做什么

总览

四张状态卡（数据桥 / 对局 / 覆盖层 / 数据新鲜度）＋实时预览＋本局玩家表。先看这里判断链路通不通。

画面

所有影响直播画面的开关：比分、单位栏、生产队列、Esc 菜单隐身、等待提示、顶栏布局，以及覆盖窗口和全局热键。

单位

搜单位 ID，给任意单位换图标或隐藏；也能按形态 / 阵营 / 状态过滤。改动会同步到 OBS。

环境

游戏路径、权限、分辨率、桥文件等自检项，出问题时先把这里的报告复制出来。

日志

程序自己的运行日志，支持按级别过滤和搜索。反馈问题时贴这里的内容最有用。

常见问题

HUD 一直显示「等待进入对局」

说明数据桥还没读到对局。确认游戏真的进了地图（不是停在大厅）， 再看「总览」页「数据桥」卡是不是「托管运行中」。可以在「环境」页点「重启数据桥」。

单位栏里出现没图标的方块

该单位在原版美术里就没有 cameo（如焚风飞蜥炮台 DRACOD）。 程序不会用别的图凑数以免误导，方块里会写单位 ID。

覆盖层浮在桌面上 / 和游戏画面错位

九成是全屏模式导致的。覆盖层是独立窗口，只能贴在窗口化的游戏上； 到游戏「Options → Display」勾上 Windowed Mode（可再加 Borderless Windowed Mode），见本页顶部的参考图。

按 Esc 后队列没自动收起

确认「画面」页的「Esc 菜单时隐藏队列」是开的。若仍然不收起， 到「日志」页搜 phase 看状态，并把那条反馈出来。

鼠标指针指示器什么时候出现

默认只有指针压到 HUD 面板上才画（游戏画面内不出现）。 想让它常亮，到「画面」页关掉「仅在遮挡时显示指针」。

三个窗口的关系

控制台

就是本窗口。只改状态，不渲染 HUD。

覆盖层

贴在游戏窗口上的透明窗口，加载 /overlay。只在这台机器上显示。

OBS 浏览器源

加载同一个地址，所以控制台一改，两端同时生效。

只有「覆盖窗口」分区里的开关是仅本地生效的（置顶、失焦隐藏、显隐、热键）， 其余开关都会同步到 OBS 画面。
关掉覆盖窗口不影响直播：OBS 采集的是浏览器源，不是这个窗口。

操作边界

本程序对游戏只读：只做 OpenProcess(VM_READ) 和窗口状态查询， 不注入 DLL、不打补丁、不改内存、不模拟按键。

因此它不会影响对局公平性，也不会被反作弊误判； 代价是看不到游戏没有暴露给你的信息。

三个窗口的关系

控制台（本窗口）只负责改状态，不渲染 HUD。

覆盖层是贴在游戏窗口上的透明窗口，加载 /overlay。

OBS 浏览器源加载同一个地址，所以控制台一改，两端同时生效。

只有「覆盖窗口」分区里的开关是仅本地生效的（置顶、失焦隐藏、显隐、热键）， 其余开关都会同步到 OBS 画面。
